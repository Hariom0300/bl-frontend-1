# Dongare Fashion Frontend

## 🛍️ Modern E-commerce Store

A responsive, modern e-commerce frontend for Dongare Fashion brand.

### 🌐 Live URLs
- **Vercel:** https://bl-frontend.vercel.app
- **GitHub Pages:** https://hariom0300.github.io/BL-frontend

### 📱 Features
- ✅ Responsive design (Mobile-first)
- ✅ Product catalog with search/filter
- ✅ Shopping cart functionality
- ✅ User authentication
- ✅ Order management
- ✅ Modern UI/UX
- ✅ API integration ready

### 🛠️ Tech Stack
- **HTML5** - Semantic markup
- **CSS3** - Modern styling with animations
- **JavaScript ES6+** - Vanilla JS, no frameworks
- **REST API** - Backend integration

### 🚀 Quick Start

1. **Clone repository:**
   ```bash
   git clone https://github.com/Hariom0300/BL-frontend.git
   cd BL-frontend
   ```

2. **Start local server:**
   ```bash
   npm run dev
   # or
   python -m http.server 8000
   ```

3. **Open browser:**
   Navigate to `http://localhost:8000`
